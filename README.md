# Chroma

Currently based on Chroma PC v2.5.0 as of this time

Colors!

## Background missing? Does the map not look like you expected?
Please confirm this issue isn't related to [#26](https://github.com/bsq-ports/Chroma/issues/26)! Make sure all the environment effects are turned on (located under `Player Settings`).

### NOTE: This is a port of Chroma to Quest Standalone. As such, it is in no way associated with Aeroluna. Please do not pester them about bugs, because they are not associated with this port.
